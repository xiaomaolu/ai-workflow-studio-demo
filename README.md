# AI Workflow Studio Demo

A single-page AI workflow product demo for a Twitter auto-publishing workflow.

## Files

- `index.html` - deployable entry for GitHub Pages or Vercel.
- `agents-workflow-editor-fork.html` - source demo file kept for local sharing.
- `vercel.json` - static single-page routing config.

## Deploy

This project is static HTML and can be deployed directly to Vercel, GitHub Pages, or any static host.
